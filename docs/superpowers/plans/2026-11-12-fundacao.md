# Fundação (Módulo 0) — Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transformar o fork do MuMuAINovel numa base em português, sem dependências do projeto original, com Codex (assinatura ChatGPT Pro) como motor de IA com reserva via API, Qdrant no lugar do ChromaDB, idioma de saída por projeto e os modelos de dados que os próximos módulos vão usar.

**Architecture:** O backend FastAPI e o frontend React continuam. A Fundação:
- adiciona uma base de testes (hoje não há nenhum);
- extrai os prompts para um pacote próprio traduzido;
- coloca o banco vetorial atrás de uma interface (implementada com Qdrant);
- adiciona um provider `codex` que chama o CLI oficial por subprocesso, com reserva automática para um provider de API.

O frontend ganha i18n (react-i18next) com locale pt-BR e perde as telas ligadas ao projeto original.

**Tech Stack:**
- Python 3.12, FastAPI, SQLAlchemy async, Alembic (árvores `sqlite` e `postgres`), pytest + pytest-asyncio;
- qdrant-client (modo embutido local ou servidor);
- ONNX embedding `paraphrase-multilingual-MiniLM-L12-v2` (384 dimensões, cosseno);
- Codex CLI (`codex exec`, testado com codex-cli 0.167.1);
- React 18 + Vite + Ant Design 5 + react-i18next.

**Spec:** `docs/superpowers/specs/2026-11-11-fabrica-de-ebooks-design.md`

## Global Constraints

- **Branch:** trabalhar no branch `feat/fundacao` (criado a partir de `main`); nunca commitar direto em `main`.
- **Python:** 3.12 (imagem Docker `python:3.12-slim`). Localmente: `uv venv --python 3.12 backend/.venv`.
- **Mudanças de schema:** toda mudança de schema tem migração nas **duas** árvores: `backend/alembic/sqlite/versions/` e `backend/alembic/postgres/versions/`. A cabeça atual de ambas é `20260914_knowledge`.
- **Fork independente:** "O fork segue por conta própria" — reestruturar arquivos é permitido.
- **Gemini:** "Gemini: usar só por chave de API, nunca pelo login da assinatura."
- **Codex:** usado **apenas via CLI oficial `codex`** (`codex exec`). Proibido ler/extrair o token OAuth de `~/.codex` ou chamar o backend do ChatGPT diretamente.
- **Idioma:** interface em PT-BR; conteúdo gerado no idioma do projeto (`Project.language`, padrão `pt-BR`).
- **Embedding:** `paraphrase-multilingual-MiniLM-L12-v2` ONNX, vetores de **384** dimensões, distância **cosseno**.
- **Escopo da tradução no backend:** logs (`logger.*`), comentários e docstrings podem continuar em chinês (decisão do plano). Toda string que chega ao usuário ou à IA precisa estar em PT-BR: respostas HTTP, eventos SSE, prompts, cabeçalhos de contexto e dados semeados.
- **Dono único:** chaves, provider Codex e configurações globais são do admin; não criar cota por usuário.
- **Volume esperado:** 2 low tickets + 1 ficção por semana. Concorrência do Codex limitada a **2** execuções simultâneas.

## Review Focus

1. **Cota ou login do Codex falhando no meio de uma geração.** Com reserva configurada, a geração continua pela API sem perder o pedido. Sem reserva, o usuário vê um erro claro em PT-BR, sem stack trace. Teste na Task 9.
2. **Modelos de prompt personalizados no banco** (`prompt_templates`, criados antes da tradução) sem `{output_language}` ou com chaves chinesas. A formatação não pode quebrar com `KeyError`: argumentos extras são ignorados e o idioma ainda é imposto pelo prompt de sistema. Teste na Task 3.
3. **Busca vetorial em coleção vazia, `limit` maior que o total de pontos, ou ids que não são UUID** (ex. ids estáveis de foreshadowing). Deve devolver lista vazia ou resultados, nunca exceção. Teste na Task 8.
4. **Texto com Markdown, emojis, números e preços** ("R$ 19,90", "**negrito**", "😀"). A contagem de palavras precisa ser plausível e o texto vazio ou `None` deve dar 0. Teste na Task 1.
5. **Codex travado ou demorando demais.** Depois de `timeout_s` o processo é morto e vira `CodexTimeoutError`, tratado como falha que aciona a reserva. Teste na Task 9.
